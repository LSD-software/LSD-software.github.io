LSD Console update
- Replaced the console splash logo with the approved transparent, hand-drawn console + Wii-style controllers illustration.
- Added console-specific favicon/touch icon.
- PWA standalone mode is restricted to Hub and game routes; informational/account pages attempt to open their requested URL in a browser tab and return the installed app to Hub. Browser mode is unaffected.
- Removed automatic API /health pings on page load to avoid unnecessary requests and ERR_BLOCKED_BY_CLIENT noise from privacy extensions.
- Updated Lucide CDN fallback URLs to valid package distribution paths.

Note: opening a separate browser tab from an installed PWA can be blocked by browser policy; the app always falls back to Hub in that case.


Cover correction: the classic LSD Software logo is used on the LSD Console loading splash; the hand-drawn console/controller illustration is used as the LSD Console cover on Hub and Projects. Game logic was not modified.
